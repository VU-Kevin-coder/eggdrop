# Assets folder

The game runs perfectly well with **no files in this folder at all** -
every loader in `game/assets.py` and `game/audio.py` falls back
to a procedurally generated image or silently skips a missing sound.
Drop real files in using the exact names below and they'll be picked
up automatically, with **no code changes required**.

## backgrounds/
- `house.png`
- `market.png`
- `road.png`
- `construction.png`
- `grandma_house.png`

Any resolution works. These images are displayed as small destination
illustrations at the level exit, not stretched across the game window.
The playable backdrop is generated by the game so the UI remains clear.

## characters/
- `player.png` - the player sprite (recommended ~48x64 transparent PNG)
- `npc.png` - shared NPC sprite (recommended ~44x60 transparent PNG)

## objects/
- `egg.png` - the egg (recommended ~34x42 transparent PNG). The game
  draws cracks on top of this image automatically as it takes damage,
  so a single clean "perfect egg" image is all that's needed.
- `box.png`, `construction_barrier.png`, `car.png` - optional; used
  automatically by matching obstacles if present.

## sounds/ (.wav recommended)
`pickup.wav`, `drop.wav`, `footsteps.wav`, `egg_wobble.wav`,
`small_impact.wav`, `large_impact.wav`, `crack.wav`, `egg_break.wav`,
`button_click.wav`, `level_complete.wav`, `game_over.wav`, `success.wav`

## music/ (.ogg recommended)
`menu_theme.ogg`, `gameplay_theme.ogg`, `victory_theme.ogg`
